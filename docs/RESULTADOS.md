# Resultados de pruebas

Los resultados anteriores correspondían a otra versión del proyecto. Para generar el informe del alcance actual, ejecutar `npm test`.

El comando ejecuta las pruebas de la tienda en Chromium y genera este documento, COBERTURA.md y los informes JSON. En GitHub Actions se descargan desde el artefacto `cobertura-y-resultados` de cada ejecución.
